# BurmalPico

A simple command-line program for the Raspberry Pi Pico.

BurmalPico runs on top of MicroPython and provides its own terminal and commands.

## Features

- LED control
- LED blink modes
- Custom LED patterns
- LED pattern slots
- Reaction time test
- System information

## Commands

led on

led off

led blink

led blink inf

stop

led status


led bit (0-1)

led bit save 1 (0-1)

led bit 1

led bit 2

led bit 3

reaction

fetch
